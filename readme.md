
# YouTube Notes Maker

A Python project that extracts video IDs from YouTube URLs. This is the first step toward building a tool that retrieves video transcripts and generates AI-powered notes.

## Current Features

- Accepts a YouTube URL as user input.
- Validates supported URL prefixes.
- Extracts the video ID from supported standard and shortened URLs.
- Returns and displays the extracted video ID.

## Tech Stack

- Python

## How to Run

1. Clone this repository.
2. Open the project directory.
3. Run:

   ```bash
   python3 main.py
   ```

4. Paste a supported YouTube URL when prompted.
